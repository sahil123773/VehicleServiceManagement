# Vehicle Service Management System

A web-based Vehicle Service Management System developed using ASP.NET Core MVC.

## Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- Bootstrap
- HTML/CSS/JavaScript

## Features

- Customer Management
- Vehicle Management
- Service Management
- Dashboard
- Create, Read, Update and Delete operations
- Form validation
- Delete confirmation
- SQL Server database integration

## Project Structure

- Controllers
- Models
- Data
- Views
- Migrations
- wwwroot
